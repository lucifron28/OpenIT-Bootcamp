Design a Movie Watchlist REST API - Levels 2 & 3

Scenario: Build a REST API for a Movie Watchlist (title, year, genre, watched: bool, rating: float)

1. Design 6+ endpoints using correct HTTP verbs (Level 2):
GET /movies/{id}
PUT /movies/{id} DELETE /movies/{id} GET /movies/{id}/reviews

2. For GET/movies - add query parameter support:
?genre=action & ?watched=false & ?sort=rating&order=desc & ?page=1&size=5

3. Explain the difference between GET /movies/5 and GET /movies?id=5
When should you use each? (discuss with a classmate)

4. Add a HATEOAS _links section to GET /movies/{id} with at least 5 links

5. What HTTP status codes would you return for:
Successful creation? Resource not found? Validation error?
